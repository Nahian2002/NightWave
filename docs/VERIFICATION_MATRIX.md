# Verification guide

- **Source checks** exercise structural contracts and negative fixtures.
- **JVM tests** exercise host behavior. The Windows build also compiles Android test sources and produces the APK.
- **Lint and signing** check the built source and its install identity.
- **Phone evidence** covers observed journeys on the named build and device. Broader scenarios remain open until tested.
