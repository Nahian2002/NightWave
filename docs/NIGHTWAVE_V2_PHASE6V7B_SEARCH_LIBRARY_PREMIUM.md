# NightWave 6V7B — Search & Library Premium Redesign

Based on 6V7A, preserving the same Media3 service, playlist storage, search
sources, offline files, Google Drive backup, LRC lyrics and app identity.

## Implemented

- A new **Find your sound** Search introduction with restrained gradient,
  original icons, premium typography and truthful text describing discovery.
- A compact, theme-adaptive **Library header** for saved tracks and individual
  playlists, without rewriting the playlist hierarchy or selected playlist.
- Shared, smaller, artwork-first track tiles. Search rows and Library rows
  carry separate surface roles; all images still load from authentic existing
  `VideoPreview.thumbnail` values. Missing thumbnails display the current
  neutral art fallback rather than invented artist photos.
- Compact playlist collection tiles with 56dp artwork, consistent corners,
  accessible existing tap targets, and their original `onClick` action.
- Navigation/mini-player changes from 6V7A and all earlier playback, lyrics,
  offline and Drive code remain unaffected.

## Test declarations and gates

- 8 JVM unit tests in `NightWaveCollectionChromeTest`: phone widths,
  nonfinite layout widths, negative counts, correct source labels and card
  sizing.
- 3 isolated Compose UI tests in
  `NightWaveSearchLibraryChromeInstrumentedTest`: narrow Search header,
  large playlist names, and collection onClick.
- Earlier pager/navigation, mini-player and lyric tests remain in place.
- `tools/verify_v2_phase6v7b.py` is a self-testing static gate in GitHub CI.
- `tools/check-phase6v7b-integration.ps1` is the Python-free Windows
  preflight. The previous Gradle unit tests, Android test-source compile,
  `assembleDebug` and signing checks are still required.

## How to check later

1. Extract the full source archive into a fresh folder.
2. Run `build-windows.cmd` and require all tests, `BUILD SUCCESSFUL`,
   and APK package/signature checks. Do not install a stale debug APK.
3. On a disposable Android device, inspect Search, Home and Library at
   320dp and larger sizes, including light and dark themes.
4. Search online and in saved songs. Verify that the result itself and its
   three-dot action target the expected song.
5. Open playlists, select tracks, create a playlist, search and sort
   collections. Check that existing saved ordering and data remain intact.
6. Confirm original authentic thumbnails or the neutral placeholder;
   no broken, fake or permanently missing artwork should be claimed.
7. Regress playback, mini-player gestures, queue, lyric editor, Google
   Drive Music Vault, offline audio and recent 6V7A tab navigation.
8. Confirm in-place signer compatibility with `check-device-update.cmd`
   before any installation; never uninstall or clear saved app data.
