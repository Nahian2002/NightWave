## The apparent automatic Search text

At 02:24–02:26 the field shows **Song or artist name**. At 02:26 a caret appears before that text, with no clear-query button. Source corroborates that it is an empty-field placeholder: `value = query` is separate, the initial query is empty, and the placeholder is a `Text` composable. Page navigation/focus does not itself submit a public search. Existing saved-library suggestions are local and do not imply a public request.

A separate real weakness exists: `LaunchedEffect(state.query)` previously copied any retained provider query back into the editable draft when the pager recreated Search. That could resurrect a query already cleared or edited. The fix gives explicit Home/shared-text prefills a unique transient token and saves its consumption alongside the draft. Provider results have no prefill token and cannot overwrite text. The same shortcut can still be intentionally opened again because each explicit request has a fresh token. This affects presentation state only, not saved history, providers, original URLs or backup formats.

The revised hint says **Search songs, artists or links**, uses the theme's supporting-text color and disappears while focused. The editable value remains empty until typing or an intentional shortcut. Input retains its semantic search name, keyboard submit, clear control, local suggestions, modes and public/offline alternatives. No blanket query/history clearing on navigation is introduced.

## Applied polish

- Navigation becomes a flat canvas-colored rail. Selection is a smaller icon capsule, retaining all four labels, full tab targets, semantics, reduced motion and animations.
- The raised mini-player uses a 16dp corner and aligned 16dp gutters, with its duplicated outer stroke removed. Playback, hide/restore, swipe, progress, queue/next and expanded-player actions remain.
- Shared secondary buttons use solid theme raised surfaces and readable primary text without default outline strokes. Explicit caller borders/colors remain supported. Primary controls retain the accent and tested paired ink; disabled behavior remains Material-owned.
- Decorative Material separators use a softer outline-variant role. Required control outlines and text roles are unchanged; they are not globally faded.
- The Search field receives explicit selected-theme container/border/cursor roles. Existing artwork, four palettes, collection content, native/classic choice, type scaling, hit targets and feature routes remain.

Five executed-policy regression methods cover absent/consumed/fresh explicit requests; the existing 36-configuration Android Search method additionally checks focus hint removal, exact submitted text, late-provider non-overwrite, clear/recreate retention and repeat explicit shortcut handling. Instrumentation compilation is not execution: the ten-method matrix remains **360 compiled cases, NOT_RUN**. Two additional broken caller fixtures protect this wiring inside the existing 62-check runner (12 expressive negative fixtures total).
